Google Chrome / Brave / Edge

Ready-to-load Manifest V3 package

  1. Download and unzip the .zip archive.
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the extracted folder.
📥 Download for Chrome (.zip)

Mozilla Firefox

Gecko-compatible WebExtension archive

  1. Download the Firefox .zip archive.
  2. Open about:debugging#/runtime/this-firefox in Firefox.
  3. Click Load Temporary Add-on... and select the .zip file.
